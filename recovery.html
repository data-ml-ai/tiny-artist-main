Website Recovery

This separate recovery page restores the Tiny Artist website after an emergency deactivation. It deletes nothing — no source code, database records, or repository content is touched. It only clears the deactivation flag.

If the server status still says deactivated after restoring here, the site will stay blank until the server state changes: set deactivated: false in the deployed site-status.json and redeploy, or — once the backend is connected — set site_settings.deactivated = false in Supabase (see SETUP.md). In backend mode, restore requires a signed-in admin session; without one, this page clears only this browser's local flag.
